# 911 (`992.2`) for Obsidian

Precision Night Cockpit dark theme for Obsidian (tuned for Obsidian 1.14+), aligned with [`../colors.toml`](../colors.toml) and the canonical 911 cockpit palette.

## Coverage

- **4-plane cockpit surfaces**: Deep Carbon ribbon & titlebar (`#0c0e11`), Carbon sidebars & Canvas well (`#0f1114`), Race-Tex Chrome tab bar, status bar, table headers, blockquotes & Properties panel (`#131519`), Race-Tex Charcoal reading/writing canvas (`#141619`), Vanadium elevated modals, command palette, quick switcher, tooltips, popovers & code blocks (`#1a1d23` / `#1d2026`), Smoked Carmine active nav & selection (`#261b1f`) with a `2px` Guards Red needle (`#e55c5a`).
- **Editorial typography & reading ergonomics**: 5-step typographic hierarchy (`#edede9` -> `#dadad6` -> `#b4b7be` -> `#9297a2` -> `#858a96`) with restrained monochrome H1–H6 scale/weight/spacing (no rainbow headings), quiet Markdown formatting tokens, subtle active editor line tint, and crisp tabular numerals in the status bar.
- **Full component & core plugin support**: Inline & fenced code blocks with `1px` `#252932` border and full CodeMirror 6 + Prism syntax highlighting, hairline tables with hover row tints, `2px` Guards Red blockquotes, custom checkboxes (`#bf3b3e` / `#f4f3ef` `4.84:1` AA), pill tags (`#363b47` / `#261b1f`), all 14 Callouts using Obsidian 1.14+ color tokens, Properties/Frontmatter, Obsidian Bases (Table, Cards, Kanban), Graph view (silver nodes with Guards Red focus needle), Canvas cards/controls, and search highlights (`#5b5134` / `#edede9`).

## Installation

```bash
mkdir -p "<your-vault>/.obsidian/themes/911"
cp 911/manifest.json 911/theme.css "<your-vault>/.obsidian/themes/911/"
```

Then in Obsidian: **Settings → Appearance → Themes → 911**.
