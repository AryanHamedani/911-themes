# 911 (`992.2`) for Obsidian

Precision Night Cockpit dark theme for Obsidian, aligned with [`../colors.toml`](../colors.toml) and the derived 911 cockpit surfaces.

## Coverage

- **4-plane cockpit surfaces**: Deep Carbon ribbon/titlebar (`#0c0e11`), Carbon sidebar/code well (`#0f1114`), Race-Tex Charcoal canvas (`#141619`), Race-Tex Chrome statusbar/modals (`#131519`), Vanadium elevated cards/tables (`#1a1d23`), Smoked Carmine active nav (`#261b1f`).
- **Typography & Accents**: Ice Grey (`#dadad6`), Pure Highlight (`#edede9`), Guards Red filled controls (`#bf3b3e` / `#f4f3ef` `4.84:1` AA), active tab redline top indicator (`#e55c5a`), 6-level semantic headings, full Callouts RGB palette, Graph view, Canvas, CodeMirror & Prism syntax highlighting, and search match highlights (`#5b5134` / `#edede9`).

## Installation

```bash
mkdir -p "<your-vault>/.obsidian/themes/911"
cp 911/manifest.json 911/theme.css "<your-vault>/.obsidian/themes/911/"
```

Then in Obsidian: **Settings → Appearance → Themes → 911**.
