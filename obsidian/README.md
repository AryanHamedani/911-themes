# Carrera for Obsidian

A dark Obsidian theme inspired by the Porsche 911 Heritage Cockpit on a night drive:
Basalt Alcantara canvases (`#15171a` primary, `#101215` sidebars), Chalk (`Kreide`, `#d6d2c7`) prose,
OKLCH-calibrated heading hierarchy, and Carmine Red (`#e1656c`) active accents.

## Install

Copy the `Carrera/` folder into your Obsidian vault's themes directory:

```bash
cp -r obsidian/Carrera "/path/to/your/vault/.obsidian/themes/Carrera"
```

Then open Obsidian → **Settings → Appearance → Themes** and select **Carrera** (Dark mode).

> Note: Keep the directory named `Carrera` so it matches `"name": "Carrera"` in `manifest.json`.
