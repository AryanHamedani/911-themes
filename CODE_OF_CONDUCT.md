# Contributor Covenant Code of Conduct

We are committed to providing a welcoming, respectful, and harassment-free experience for everyone contributing to **911 Themes**.

- Be constructive and kind in reviews, issues, and discussions.
- Focus feedback on design, ergonomics, contrast, and code quality — never on people.
- Respect maintainers' and contributors' time.

Unacceptable behavior may be reported to the repository maintainer via GitHub.
